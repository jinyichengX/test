第 0 课：模糊到底是什么

核心概念（看完这个再去看图，每一步都能对上）
直觉： 模糊 = 把每个像素的值"匀"给邻居。离得近的邻居分得多，离得远的分得少。 怎么决定分多少？用一条钟形曲线——中间高、两边低。这条曲线就是高斯核。
高斯函数： G(x) = exp(−x² / 2σ²) x = 邻居离中心多远（像素），σ = 控制"胖瘦"的参数
σ 是什么： σ 越大，曲线越"胖"，模糊范围越大。CSS 规范中 σ ≈ blur_px / 2。 比如 blur = 10，σ = 5。那核半径取 ±3σ = ±15 像素，高斯曲线在这个范围外的高度不到峰值的 1%，截断不影响精度。
exp() 是什么： exp(某个数) 就是 e 的多少次方。e ≈ 2.718，一个数学常数。 比如 exp(0) = 1，exp(−1) ≈ 0.37，exp(−10) ≈ 0.000045。 你可以把它理解为"把一个数套进一条下降曲线"的工具，不用深究。
核权重（归一化）： kernel[k] = G(k) / ΣG(k)
为什么要归一化： 拿 G(−2)、G(−1)、G(0)、G(1)、G(2) 这五个数，加起来等于某个总和（比如 3.2）。 如果直接用它们当权重，模糊完整个画面会变亮或变暗。所以把每个数都除以 3.2，让五个数加起来恰好等于 1。 归一化 = 让所有权重之和 = 1，保证模糊不会改变画面整体的亮度。 下面的核可视化里写着"Σ = 1.00"，就是这个意思。
离散卷积（模糊的具体操作）： result[i] = Σk=−r+r input[i+k] × kernel[k]
翻译成人话： 我要算模糊后第 i 个像素的值。我把一个窗口（半径 r）扣在位置 i 上， 窗口里每个像素的值 × 它对应的核权重，全部加起来。 如果窗口里全是 1，加权和 = 1（因为核权重之和 = 1）。如果窗口里有些 0 有些 1，加权和就在 0 到 1 之间。 这就是模糊的全部操作。步骤③的可视化展示的就是这个累加过程。

第 1 课：二维阴影 = 水平模糊 × 垂直模糊

关键洞察——矩形是特殊的：一个矩形可以写成"水平方向的条"×"垂直方向的条"。 好比一个方格纸，某格子在不在矩形里，等于"它的列在不在宽度范围内"且"它的行在不在高度范围内"， 两个判断互相独立。这意味着你不需要对整张图做二维循环，只需算两个一维结果再相乘。

二维卷积 = [∫X·G dx] × [∫Y·G dy] = rowBlur[x] × colBlur[y]。

通用方法：标准两遍分离卷积（对所有形状都正确）

第 1 课的 rowBlur × colBlur 是纯矩形的特例加速，不具备通用性。 真正的通用做法是——先横向模糊一遍，再对中间结果纵向模糊一遍。 这个方法对任何形状（矩形、圆角、椭圆、不规则图形）都正确。 下面用矩形验证：结果和第 1 课完全一致。

第 3 课：圆角矩形阴影 — 方案一：SDF + CDF

对每个像素算距离 → 查 CDF 表得透明度。O(1) 每像素，不需要中间缓冲。

第一步：先理解 CDF 这个词
全称： CDF = Cumulative Distribution Function（累积分布函数）。 拆开来看：Cumulative = 累积，Distribution = 分布，Function = 函数。
"累积"是啥意思： 假设你有一排数字：3, 5, 2, 7。它们的"累积和"就是：3, 3+5=8, 8+2=10, 10+7=17。 "累积" = 边走路边把前面经过的数字全部加起来。走到哪，累积到哪。
"分布"是啥意思： 高斯模糊的钟形曲线描述了能量的"分布"——中间最多，两边逐渐减少。 如果把钟形曲线下的总面积看作 1（100% 的能量），每个位置的高度就是"这个位置分到了多少能量"。
合起来： CDF(d) 就是：从最左边（−∞）出发，沿着钟形曲线一路走到位置 d，沿途把所有高度累加起来。 因为总面积是 1，CDF(d) 就是一个 0 到 1 之间的数——走到 d 时已经"收集"了总能量的百分之多少。
举个例子： 钟形曲线的正中间（d=0）是最高的。从最左边走到 d=0，大概累积了 50% 的能量，所以 CDF(0) ≈ 0.5。 再往前走 3σ（走到 d=3σ），钟形曲线已经几乎降到 0 了，累积了差不多全部能量，所以 CDF(3σ) ≈ 1.0。
第二步：CDF 和模糊有什么关系
回到 Lesson 0 的台阶： 有一个从 1 跳变到 0 的台阶。对它做高斯模糊。 模糊后，台阶不再是硬的——在跳变位置附近，值从 1 平滑过渡到 0。
关键发现： 模糊后的台阶，在距离跳变点 d 像素处的值，恰好等于 1 − CDF(d)。 这是数学推导出来的，不是巧合。推导过程：设台阶 f(x)=1(x<0), 0(x≥0)，高斯核 g(x)，卷积： result(d) = ∫f(x)·g(d−x)dx = ∫−∞0 g(d−x)dx = ∫d∞ g(u)du = 1 − CDF(d)。
这意味着什么： 对一个台阶边缘做模糊，结果只取决于两个数——你离边缘多远（d）、模糊多大（σ）。 既然结果只取决于 d，何必每次都跑完整卷积？ 提前算好 CDF 表存起来，以后遇到台阶边缘，直接查表：CDF[d] → 透明度。
erf 是干嘛的： CDF 没有简单的算术公式（不像"y=2x+1"那种），只能用 erf（误差函数，Error Function）的近似公式来算。 erf 只是一个计算工具的名字，不用管它什么意思——它存在的唯一目的就是算出 CDF 的数值。 实际代码里把 CDF 预存成数组 cdf_lut[256] 之后，连 erf 的计算都不需要了，直接查数组下标就行。
第三步：圆角矩形 SDF — 一个公式搞定全部
SDF（Signed Distance Field，带符号距离场）： 对画面里每个像素，算出它到圆角矩形边界的最近距离。 边界内 = 负数，边界外 = 正数，边界上 = 0。
准备： 盒子中心 (cx, cy)，半宽 hw，半高 hh，圆角半径 r。 对像素 (x, y)，先取绝对值变成第一象限（四个象限对称）：
px = |x − cx|
py = |y − cy|
qx = px − (hw − r)    ← 到"内缩矩形"右边的距离
qy = py − (hh − r)    ← 到"内缩矩形"上边的距离
（内缩矩形 = 原矩形四边各内缩 r 像素。圆角的圆心就在这个内缩矩形的四个角上。）
最终公式（一行）：
SDF = min(max(qx, qy), 0) + sqrt(max(qx,0)² + max(qy,0)²) − r
这一行怎么同时处理所有区域：
① 内部（qx<0, qy<0）：max(qx,0)=0, max(qy,0)=0，所以 sqrt 部分 = 0； min(max(qx,qy),0) = max(qx,qy)（负数）。 SDF = max(qx,qy) − r = 负数 − r = 更负 = "在内部多深"。
② 直边外侧（比如 qx>0, qy<0）：max(qy,0)=0，sqrt = qx； min 部分 = 0。SDF = qx − r = 到直边的距离。
③ 角落外侧（qx>0, qy>0）：sqrt(qx²+qy²) = 到圆心的距离； min 部分 = 0。SDF = 到圆心距离 − r = 到圆弧的距离。
关键：不是"先画矩形再贴圆角"。 整个距离场是一个连续函数。在边界上，无论直边还是角落，SDF 都 = 0。 从直边走向角落，距离值平滑过渡，没有跳跃。这就是为什么阴影看起来是自然融合的。
然后查 CDF 表： SDF ≤ −blur → 全阴影 | SDF ≥ +blur → 全透明 | −blur ≤ SDF ≤ +blur → 查 CDF 表。 CDF 表只依赖 blur，和盒子形状无关。

第 3 课：圆角矩形阴影 — 方案二：两遍分离卷积

先光栅化出圆角矩形 mask，再对 mask 做水平→垂直两遍一维高斯卷积。 和第 1 课纯矩形的原理一样，只不过 mask 换成了圆角矩形。

方案二的原理（和第 1 课核心机制完全一样）
第 1 课回顾： 纯矩形的 mask = X(x)·Y(y)，所以 rowBlur × colBlur 直接出结果。 这是分离卷积的特例（因为输入图像本身就可分）。
圆角矩形怎么办： 圆角矩形的 mask 不能分解为 X(x)·Y(y)，所以不能直接 rowBlur×colBlur。 但高斯核本身是可分离的：G(x,y) = G(x)·G(y)。这意味着可以先对每行做 1D 高斯模糊， 再对中间结果的每列做 1D 高斯模糊——两遍下来等于一遍 2D 高斯模糊。
操作步骤：
① 光栅化圆角矩形 → 0/1 mask（和方案一的 c3a 完全一样）
② 对 mask 的每一行独立做 1D 高斯卷积 → 中间结果（水平已模糊）
③ 对中间结果的每一列独立做 1D 高斯卷积 → 最终阴影
代价： 需要一个和画布一样大的中间缓冲存放水平模糊后的结果。

1 光栅化圆角矩形 mask（和方案一共享同一个 mask）
2 对每行做 convolve1D(row, kernel) → 中间缓冲
3 对每列做 convolve1D(col, kernel) → 最终阴影
每像素 O(r) 次乘法，但需要 W×H 的中间缓冲。对任意形状（圆角、椭圆、不规则）都适用。
两种方案对比
方案一 SDF+CDF： 每像素 O(1)，不需要中间缓冲。但对非圆角矩形形状（如椭圆、不规则形状）需要换 SDF 公式。
方案二 两遍卷积： 每像素 O(r)，需要 W×H 中间缓冲。但对任意形状都适用 — 只要你能光栅化出 mask，就能用同样的两遍卷积流程，不需要针对每种形状推导 SDF 公式。
更普适的做法： 方案二（两遍分离卷积）。 理由：高斯核的可分离性是通用数学性质，不依赖输入形状。圆角矩形、椭圆、文字、 任意路径——只要先光栅化成 mask，后续流程完全一样。方案一需要为每种形状找一个 SDF 公式，不是所有形状都有简单的 SDF 公式。
