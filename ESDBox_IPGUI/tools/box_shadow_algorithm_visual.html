第 0 课：模糊到底是什么

核心公式（先看这个，再看图）
高斯核函数： G(x) = exp(−x² / 2σ²) → 归一化 → kernel[k] = G(k) / ΣG(k) σ ≈ blur_px / 3，x 是邻居到中心的偏移（像素）
离散卷积： result[i] = Σk=−r+r input[i+k] × kernel[k] 在位置 i 处，把核窗口内的每个输入 × 对应权重，全加起来

① 原始信号 input[i]  i = 0..279

白色 = input[i] = 1（阴影内部满），黑色 = 0（阴影外透明）
红色虚线 = 盒子边界（内部开始/结束的位置）

② 核权重 kernel[k]  k = −r..+r

柱高 ∝ 权重，数字 = 归一化后的精确值，k=0 是中心
所有数字加起来 = 1.00（保证能量守恒）

③ 对位置 i=130 执行卷积（逐个邻居加权累加）

核窗口对准位置 i=130 — 灰色条选中的 input ← → 绿色柱对应的 kernel — 每一项 = input[i+k] × kernel[k]，全部加起来 = 该位置的模糊后值

④ 最终模糊结果 result[i]

每个 result[i] 都按步骤③算一遍 → 硬边界变成柔软渐变

⑤ 位置 i=130 的最终值

—
这个值 = 该像素的 alpha（0=全透明，1=全阴影）
可直接写入 surf[i].alpha
1 生成高斯核 kernel[]（查表/运行时算）
2 对每个输出像素 i，循环 k = -r..+r 做加权累加
3 结果写入像素 alpha 通道 —— 这就是模糊的核心
对应 C 代码：for (k = 0; k < kernel_len; k++) sum += input[i + k - r] * kernel[k]; output[i] = sum;

第 3 课：圆角 > 0 时四角怎么模糊

矩形的四条边用「距离到边 × CDF 查表」即可（第1课的方法）。 但四个圆角需要距离到圆心 × CDF 查表。下面展示左上角的模糊过程。

16 8

角部放大：原始硬角

白色=阴影色满，黑色=透明

SDF 距离场

每像素到圆角边界的距离（越亮越远）

通过 CDF 查表得到阴影

距离 → CDF[d] → alpha → 阴影色
1 算出每个像素到圆角边界的 SDF 带符号距离
2 d ∈ [-blur, 0] 是阴影内部，alpha=满值
3 d ∈ [0, blur] 是过渡带，查 CDF 表（高斯积分离散化）得到 alpha
4 d > blur 是阴影外部，alpha=0
这就是你代码里 cdf_lut[256] 的作用——把「距离」翻译成「透明度」。
