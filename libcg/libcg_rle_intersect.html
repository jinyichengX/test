①数据模型：RLE = 一串 span

RLE 不存整张位图，只存「一行里 coverage 相同的连续段」。每个 span 记四样东西：x（起始列）、len（长度）、y（行）、coverage（0~255 覆盖率）。

关键不变量：spans 必须按 y 递增、同行内按 x 递增排列。双指针归并完全依赖这个顺序，否则会漏交。

③双指针归并 · 逐步执行

两个指针 a、b 分别遍历 A、B 的 span 列表。每步做三件事之一：对齐 y、判断 x 是否重叠、产出交集 span。

cg.c:1001-1070 精简交集核心逻辑
while(a_spans < a_end && b_spans < b_end) {
    if(b->y > a->y) { ++a; continue; }         // 把 y 对齐
    if(a->y != b->y) { ++b; continue; }
    int ax1 = a->x, ax2 = a->x + a->len;
    int bx1 = b->x, bx2 = b->x + b->len;
    if(bx1 < ax1 && bx2 < ax1) { ++b; continue; }  // b 在 a 左侧
    if(ax1 < bx1 && ax2 < bx1) { ++a; continue; }  // a 在 b 左侧
    int x = max(ax1,bx1), len = min(ax2,bx2) - x; // x 区间求交
    if(len) push(span(x, len, a->y, CG_DIV255(a->cov * b->cov)));
    if(ax2 < bx2) ++a; else ++b;                 // 谁先结束谁前进
}
CG_DIV255(x) = ((x) + (x>>8) + 0x80) >> 8（cg.h:212），是「x/255」的整数近似——既避开整数除法，又比朴素 /256 精确。
